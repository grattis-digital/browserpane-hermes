Display help

Resolutions are actual capture pixels. Smaller views are centered; larger views fit without stretching. Auto keeps the Raspberry Pi near 720p and uses readable 1× sizing. Presets go up to Full HD.

HiDPI changes local display density, not Chrome’s zoom. Higher values make the same desktop smaller; Native matches your monitor’s pixel density (up to 3×) when space permits. Chrome stays at 1× and does not restart. Large captures require more Pi CPU and bandwidth.

Preferences are saved in this viewer. The first connected viewer controls the shared capture; other viewers fit that resolution locally.
