Display help

Resolutions are actual capture pixels. Smaller views are centered; larger views fit without stretching. Auto keeps the Raspberry Pi near 720p and uses readable 1× sizing. Presets go up to Full HD.

HiDPI changes local display density, not Chrome’s zoom. Higher values make the same desktop smaller; Native matches your monitor’s pixel density (up to 3×) when space permits. Chrome stays at 1× and does not restart. Large captures require more Pi CPU and bandwidth.

Preferences are saved in this viewer. The first connected viewer controls the shared capture; other viewers fit that resolution locally.

Smart 2× optionally enhances enlarged, settled tiles with a local GPU model. Balanced is lightweight; Quality uses a larger RGB model with more GPU work, not a second filter on top. Larger does not guarantee better text. Both need HTTPS and hardware WebGPU; enhancement does not use a cloud service, the Pi, or Apple’s Neural Engine. Video and active scrolling keep original pixels. Unsupported or slow clients fall back automatically. Learned sharpening can change text and details: select Original pixels whenever fidelity matters. This setting does not change capture resolution, bandwidth, Chrome, or other viewers.
